# 五十音打字消除游戏

这是一个基于HTML+JavaScript的日语五十音打字消除游戏，适合日语初学者通过趣味方式练习假名和罗马音的对应关系。

👉 [🔗 点击这里直接试玩](https://nowhereman-in-galaxy.github.io/hiragana-typing-game/)
## 游戏简介

- 看到假名从屏幕顶部掉落时，快速在下方输入框输入对应的罗马音（罗马字母），即可消除假名并获得分数。
- 游戏共 40 关：清音、浊音、半浊音、拗音，平假名与片假名分开练习，并穿插混合挑战。
- 支持多种罗马音写法（如 し 可输入 shi / si，ふ 可输入 fu / hu，ん 可输入 nn）。
- 每关有目标分数，达成后自动解锁下一关。
- 连击、生命、最高分等机制让游戏更具挑战性和趣味性。

## 玩法说明

1. 打开游戏页面，点击“开始游戏”进入关卡选择。
2. 选择已解锁的关卡开始挑战。
3. 假名会从上方掉落，快速输入对应的罗马音（不区分大小写）：每敲对一个字母就射出一发子弹，最后一发命中即可消除（`shi` 是三连发）。
4. 连续正确输入可获得连击加成，错误或漏掉假名会失去生命。
5. 达到目标分数后通关，解锁下一关。
6. 生命耗尽则游戏失败，可重新挑战。
7. 按 `Esc` 暂停；切换标签页或窗口会自动暂停。越接近目标分数，假名下落越快、出现越密。

## 运行方式

1. 下载本项目所有文件。
2. 用浏览器（推荐Chrome/Edge/Firefox/Safari）直接打开`index.html`即可游玩，无需任何安装。

## 特色功能

- 关卡进度与最高分自动本地保存
- 支持平假名、片假名、混合挑战
- 连击、子弹、爆炸特效、屏幕震动等丰富反馈
- 实时合成的音效：命中音沿五声音阶随连击上行再回落，连击就是一段旋律（右上角可静音，设置会被记住）
- 响应式设计，适配不同屏幕
